# CodeAlpha Hangman Game

## Project Description
A simple word-guessing game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Random word selection
- Six incorrect guesses allowed
- Letter-by-letter guessing
- Win and lose messages
- User input validation

## Technologies Used
- Python 3
- Random module

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python hangman.py`.

## Concepts Used
- Lists
- Loops
- Conditional statements
- Functions
- Random module
